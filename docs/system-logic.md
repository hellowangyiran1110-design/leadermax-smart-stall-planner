# How the prototype works

## How markets are recommended

The map compares ten Birmingham venues. Each venue earns one point if its example stall fee is within the trader’s budget and one point if its straight-line distance from the starting location is within the trader’s limit. If the trader selects a time of day, a matching time slot earns one more point. Choosing **Any time** leaves two checks: budget and distance.

All venues tied for the highest score are marked **Recommended** if they meet at least one preference. The **Match** tab explains the result for each criterion. The trader makes the final choice by selecting **Choose this location**. The browser saves that choice so it appears on the home page and the stall dashboard.

## How a simulated sale changes the stall

Each order represents one item. Scheduled sales and the **Example order** button use the same rule: take one unit from stock, add one unit to the product’s sold count, and add its price to revenue. For example, the first £15 Rose Quartz Bracelet sale takes revenue from £120 to £135, orders from 8 to 9, and bracelet stock from 16 to 15.

**Pause trading** holds the current figures so the trader can inspect them. **Reset** restores the starting stock, sales totals and timer. The selected market stays saved.
