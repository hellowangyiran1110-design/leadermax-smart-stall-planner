# Market Explorer · Birmingham

This page uses MapLibre GL JS and OpenFreeMap/OpenStreetMap; attribution is displayed on the map. It requires internet access for map assets. Ten candidate venue markers are approximate, not guaranteed available pitches. Event dates, product eligibility and fees need confirmation with organizers; the cited Alternative Artisans event of 15 November 2026 has passed.

Stall fees, event time slots, revenue scenarios and footfall are example data. The 1/2/3 orders per hour and £15 average sale are fictional and do not forecast earnings. Revenue is before costs. Ranking uses example fees and times plus approximate straight-line distance; it is not AI or live data.

The entered UK postcode is sent to Postcodes.io only when Set is pressed. Starting point and destination coordinates are sent to the Valhalla demo when Show walking route is pressed, and on subsequent location changes. Route calculations are estimates; verify accessibility. Sound can be muted. The selected map location is saved locally and is shown on Home when both pages are served from the same origin. The initial 2/5 progress is an illustrative baseline; selection adds one step.
